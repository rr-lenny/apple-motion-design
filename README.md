# apple-motion-design
Animation motion design style Apple avec React, HTML et CSS

## Keynote Text Motion

`index.html` — animation de texte style keynote, autonome (HTML/CSS/JS dans un seul fichier).
Ouvrez-le directement dans un navigateur.

- Mots en entrée « flou → net » (blur 12px, translateY 20px, décalage de 80 ms), sortie floutée vers le haut.
- Démo menu contextuel (sélection + bulle Think | Generate) et démo dossier qui s'ouvre (cartes en éventail + verre dépoli).
- Scénario modifiable dans le tableau `SCRIPT` ; la séquence boucle, bouton « Rejouer » en bas.
- Respecte `prefers-reduced-motion` (pas de flou).
